# Gulf Cities Cooling-Electricity Prediction — Reviewer Evidence

This repository hosts public derived diagnostic outputs for a single-year, four-city EnergyPlus emulator comparison. It **does not** demonstrate real building-electricity savings, adequately served HVAC performance, or causal humidity effects. The five-city climate-only screen is distinct from the four-city simulator evaluation.

Reviewer data, verifier, figures and documentation are being populated. No raw NASA POWER or DOE/PNNL EnergyPlus source archive will be redistributed here pending source-rights review.
